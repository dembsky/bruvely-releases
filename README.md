# Bruvely for Mac releases

Update feed and downloads for the Bruvely macOS menu bar app.

- `appcast.xml` is the Sparkle update feed consumed by the app.
- DMG downloads are attached to the rolling
  [downloads release](https://github.com/dembsky/bruvely-releases/releases/tag/downloads).

Releases are published by `scripts/release.sh` in the (private) app
repository. Source code is not hosted here.
